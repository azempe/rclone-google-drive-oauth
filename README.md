# Rclone Google Drive OAuth

Este repositório apresenta o cliente OAuth pessoal usado para conectar o [rclone](https://rclone.org/) ao Google Drive do titular da conta. Ele não oferece acesso a terceiros nem é um serviço público de sincronização.

O rclone usa a permissão `drive.file` para acessar arquivos autorizados pelo titular durante a sincronização. Consulte a [política de privacidade](PRIVACY.md) para saber como os dados e tokens são tratados.

Para dúvidas, abra uma [issue](https://github.com/azempe/rclone-google-drive-oauth/issues).
